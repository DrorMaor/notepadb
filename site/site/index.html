A notepad. But only for databases.

Connect to a server and start typing. notepaDB suggests the real table and column names from that database, runs your SQL when you press F5, and shows the results in a grid.

$pipx install notepadb
Source code

First install pipx and Tk: sudo apt install pipx python3-tk on Debian, Ubuntu or Mint. Fedora, Arch, openSUSE, macOS and Windows

  • EnginesSQL Server, PostgreSQL, MySQL, MariaDB, Oracle and SQLite
  • Runs onLinux, macOS and Windows
  • NeedsPython 3.9 to 3.14 with Tk
  • Asks forNo account. Sends no telemetry.

    At home on a Linux desktop
    
      
    notepaDB reads your desktop's settings when it starts, so on GNOME it matches the apps around it.
    
      
      
        
    • Light or dark, your choiceFollows the GNOME style setting, or stays light or dark: View → Theme.
      • 
        
    • Your fontsUses your interface and monospace fonts. That's Adwaita Sans and Adwaita Mono on GNOME 48 and later, and Cantarell on Debian.
      • 
        
    • Adwaita colors and controlsGNOME's blue, rounded buttons and fields, underline tabs and thin scrollbars.
      • 
        
    • Sharp at any scaleIcons are drawn from vector shapes at startup, so they stay crisp at 200% scaling.
      • 
        
    • The GNOME file chooserOpen and Save use it through zenity, when zenity is installed.
      • 
        
    • X11 and WaylandTk draws through X11, so on a Wayland session notepaDB runs through XWayland, like other Tk apps.

    Five engines. One window.
    
      
    Pick the engine in the Connect dialog. After that everything works the same way: the editor, autocomplete, schema sidebar, results and history. notepaDB writes the engine-specific SQL for you.

    Coming from SSMS?
    
      
    Your habits carry over. SQL Server Management Studio runs only on Windows, and Microsoft retired Azure Data Studio on February 28, 2026. notepaDB runs on Linux, macOS and Windows.
    
      
    Prefer to work inside an editor? Microsoft points Azure Data Studio users to its MSSQL extension for VS Code, which also runs on all three. notepaDB is the small window you open for a quick query.

    Small things that add up
    
    
      
      
    • NULLs are gray in the grid, so a NULL never looks like the text 'NULL'.
      • 
      
    • Copy cells with headers from the grid's right-click menu puts tab-separated rows and their column names on the clipboard.
      • 
      
    • CSV exports open cleanly in Excel, accents and Hebrew included, because they're written with a UTF-8 BOM.
      • 
      
    • Opens .sql files saved as UTF-8, Windows-1255 (Hebrew) or Windows-1252.
      • 
      
    • Format SQL uppercases keywords and re-indents the selection or the whole tab.
      • 
      
    • The grid shows the first 2,000 rows of a result and tells you when there are more.
      • 
      
    • Bracket matching, a highlighted current line, line numbers and word wrap.
      • 
      
    • Editor zoom with Ctrl+= and Ctrl+-, remembered between sessions.

    Install
    
      
    notepaDB is a regular Python package. pipx installs it into an environment of its own and puts the notepadb command on your PATH.
    
      
    Installing brings the drivers for all five engines with it. A missing system library only matters when you connect with that engine.
    
    
    
    
    
      
    
        
    
          
          
          
          
        
    

        
    
          
    
            
    
              
              
              
              
            
    
            
    
              
    
                
    $ sudo apt install pipx python3-tk
$ pipx ensurepath
$ pipx install notepadb
$ notepadb
    
                
              
    
            
    
            
    
              
    
                
    $ sudo dnf install pipx python3-tkinter
$ pipx ensurepath
$ pipx install notepadb
$ notepadb
    
                
              
    
            
    
            
    
              
    
                
    $ sudo pacman -S python-pipx tk
$ pipx ensurepath
$ pipx install notepadb
$ notepadb
    
                
              
    
            
    
            
    
              
    
                
    $ sudo zypper install python3-pipx python3-tk
$ pipx ensurepath
$ pipx install notepadb
$ notepadb
    
                
              
    
            
    
          
    
          
    Why not plain pip install? Debian, Ubuntu, Mint, Arch and openSUSE Tumbleweed mark the system Python as externally managed (PEP 668), so pip outside a virtual environment stops with error: externally-managed-environment. pipx makes that environment for you.
    
          
    Using uv? uv tool install --no-managed-python notepadb runs it on your distribution's Python and Tk, which render fonts better on Linux than uv's own Python builds.
    
          
    On Python 3.15, for example Fedora 45, the SQL Server driver pyodbc has no prebuilt package yet, so install on Python 3.14 with uv tool install --managed-python --python 3.14 notepadb.
    
        
    

        
    
          
    
            
    $ brew install uv
$ uv tool install --managed-python --python 3.14 notepadb
$ notepadb
    
            
          
    
          
    uv's own Python 3.14 includes Tk, so there's nothing else to install. It's pinned to 3.14 because Homebrew's Python is now 3.15, and the SQL Server driver pyodbc has no prebuilt package for 3.15 yet. If the notepadb command isn't found, run uv tool update-shell and open a new terminal.
    
          
    On a Mac, notepaDB's menus sit in the menu bar at the top of the screen, like other Mac apps.
    
        
    

        
    
          
    
            Download notepadb.exe
            
          
    
          
    
            
    > winget install --id=astral-sh.uv -e
> uv tool install --python 3.14 notepadb
> notepadb
    
            
          
    
          
    Open a new terminal after installing uv. uv uses your Python 3.14 if you have one, or fetches its own, and both include Tk. Already on Python 3.9 to 3.14 from python.org? py -m pip install notepadb works too, if Python's Scripts folder is on your PATH.
    
          
    A standalone notepadb.exe that needs no Python is built for each tagged release on GitHub. None has been published yet.
    
        
    

        
    
          
    
            
    $ git clone https://github.com/DrorMaor/notepadb.git
$ cd notepadb
$ python3 -m venv .venv && . .venv/bin/activate
$ pip install -r requirements.txt
$ python -m notepadb
    
            
          
    
          
    SQLite is the easiest engine to try a change against, since it needs no server.
    
        
    
      
    
      
      
        
    • SQL ServerNeeds Microsoft's ODBC Driver 18 for SQL Server (msodbcsql18). On Linux and macOS it comes from Microsoft's package repository and brings unixODBC with it: see the guides for Linux and macOS.
      • 
        
    • OracleRuns in thin mode, so there's no Instant Client to install.
      • 
        
    • SQLiteUses Python's built-in module. Nothing extra.

    Small enough to read
    
      
    About 7,300 lines of Python in five modules, built on Tkinter. Settings, history and autosaves are plain files on your computer, and the only connections notepaDB opens are to your databases.
    
      
    What it isn't: there are no table designers, diagrams, schema compare or admin screens. Keep SSMS, DBeaver or your IDE for those.

    Questions
    
      
    Something else? Open an issue on GitHub.
    
    
    
    
    
      
    
        Is notepaDB free?
        
    Yes. It's free and open source under the GPL-2.0 license. If it saves you time, you can buy the author a coffee.
    
      
    
      
    
        Which databases does it work with?
        
    SQL Server, PostgreSQL, MySQL, MariaDB, Oracle and SQLite. Each tab connects on its own, so you can have several engines open side by side.
    
      
    
      
    
        Does it run on Linux?
        
    Yes. The screenshots on this page are from GNOME 48 on Debian 13. Install it with pipx after adding Tk from your distribution's packages, as shown under Install.
    
      
    
      
    
        Why does pip install notepadb fail on Ubuntu or Debian?
        
    Those distributions protect the system Python (PEP 668), so pip refuses to install into it and prints error: externally-managed-environment. Use pipx install notepadb, which creates a separate environment for the app.
    
      
    
      
    
        Which Python versions work?
        
    Python 3.9 to 3.14, with Tk. On 3.15, the SQL Server driver pyodbc has no prebuilt package yet, so installing would mean compiling it. The install steps above pin 3.14 wherever 3.15 is the default.
    
      
    
      
    
        Does it run on macOS and Windows?
        
    Yes. notepaDB is Python and Tk, and both run on macOS and Windows. It follows the system's light or dark setting there too, and on a Mac the menus move to the menu bar at the top of the screen. Install it with uv as shown above, and please report anything that looks wrong.
    
      
    
      
    
        Does it store my passwords?
        
    No. Saved connections, recent servers and restored sessions keep everything except the password. Tabs that use Windows authentication or SQLite reconnect on their own; the others ask you to connect again.
    
      
    
      
    
        Where are my settings and history kept?
        
    In files on your computer. notepaDB has no telemetry and no account, and it only connects to the databases you choose.
    
      
    
      
    
        How many rows does the grid show?
        
    The first 2,000 rows of each result set. The footer under the grid says how many rows the query returned, so you know when there are more. Export CSV under the grid saves the rows the grid shows; to export a whole table, right-click it in the sidebar and pick Export table to CSV, which writes up to 100,000 rows.
    
      
    
      
    
        Is it a replacement for a full database IDE?
        
    It covers writing and running SQL: autocomplete, results, explain plans and history. It has no table designers, diagrams or admin screens. Keep your IDE for those and open notepaDB for the quick work.
    
      
    
      
    
        Is the demo on this page the real app?
        
    It's a browser copy of the notepaDB window. The autocomplete follows the desktop app's rules, ported to JavaScript, and queries run on SQLite compiled to WebAssembly. The desktop app itself is Python and Tk; the screenshots show it on GNOME.
    
      
    
      
    
        How do I report a bug?
        
    Open an issue on GitHub with the engine, your OS and Python version, and the steps to reproduce it. Leave out real connection strings, hostnames and credentials.
